PDF to XTC Converter

PDFs are fixed-layout, so PicoRead can't reflow them like an EPUB. This tool renders each PDF page to a bitmap image in your browser and packs it into a .xtc file - PicoRead's native pre-rendered-page format (same one used by image-based books). No reflow, but fully readable. Everything happens locally in this browser tab; nothing is uploaded anywhere except straight to this device.
